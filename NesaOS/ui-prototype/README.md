# NesaOS UI prototype

Open `index.html` in a desktop browser to preview the round 466 × 466 watch interface. The prototype demonstrates the home screen, glanceable widget cards, circular app launcher, and settings panel.

This is a visual interaction mockup only. Weather/health values and connection indicators are placeholders; the app icons do not launch real apps. The install-app entry is a design placeholder pending verification of package installer and signing support on the target.
